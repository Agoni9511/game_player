# 陪玩微信小程序

基于 uni-app、Vue 3、TypeScript 和 Pinia。当前已接入顾客订单、陪玩接单、履约和售后能力；后端与管理后台已具备钱包、支付、陪玩师收益、提现审核等完整能力，小程序端仍需接入对应页面和接口。

## 开发

```powershell
npm install
npm run dev:mp-weixin
```

若不需要常驻热更新，也可以执行 `npm run build:mp-weixin:dev` 生成使用本地接口的开发构建。

可在微信开发者工具中直接导入当前 `miniapp` 目录，根目录的 `project.config.json` 会将小程序目录指向 `dist/dev/mp-weixin`。正式构建使用 `npm run build:mp-weixin`，产物位于 `dist/build/mp-weixin`。不能导入 `miniapp/src`。

本地接口地址由 `.env.development` 配置；真机调试不能使用 `localhost`，需改为同一局域网内可访问的地址，并在微信平台配置合法域名。

## 目录

- `src/api`：按身份划分的现有后端接口
- `src/config`：运行环境配置
- `src/services`：请求、Token 和通用基础设施
- `src/stores`：登录用户及角色状态
- `src/types`：接口公共类型
- `src/pages/customer`：顾客订单与售后
- `src/pages/player`：陪玩接单与履约
